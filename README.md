# Image Color Picker

A simple Python tool to inspect pixel colors from images and save selected values to a text file.

---

## Features
- Load image files (`PNG`, `JPG`, `BMP`, `WEBP`, etc.)
- Live RGB / HEX inspection and pixel coordinate display
- Click to collect colors and export them to a `.txt` file

---

## Dependencies
- Python 3.12
- Pillow

---

## Usage
```bash
conda env create -f environment.yml
conda activate color_picker
python src/main.py
```
